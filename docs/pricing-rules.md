# 주문 요금 계산 규칙

> 이 문서는 **코드를 읽지 않아도 이해할 수 있게** 쓴 업무 규칙서다.
> 규칙이 바뀌면 코드와 이 문서를 함께 고친다.

---

## 계산 순서

순서가 바뀌면 최종 금액이 달라진다. 순서 자체가 규칙이다.

| 단계 | 내용 |
|---|---|
| ① 상품 합계 | 단가 × 수량을 모두 더한다 |
| ② 등급 할인 | 상품 합계에서 등급별 비율만큼 뺀다 |
| ③ 쿠폰 할인 | **등급 할인이 적용된 금액**에서 다시 뺀다 |
| ④ 배송비 | 기본 3,000원. 단 조건을 만족하면 무료 |
| ⑤ 최종 금액 | 할인된 상품 금액 + 배송비 |

---

## 등급별 할인율

| 등급 | 할인율 |
|---|---|
| 일반 | 0% |
| 실버 | 3% |
| 골드 | 5% |
| VIP | 10% |

원 단위 미만은 반올림한다.

---

## 쿠폰

| 코드 | 종류 | 값 | 설명 |
|---|---|---|---|
| `WELCOME5000` | 정액 | 5,000원 | 신규 가입 할인 |
| `SPRING10` | 정률 | 10% | 봄맞이 할인 |
| `BIGSALE` | 정액 | 50,000원 | 대형 할인 |

- 쿠폰은 **한 번에 하나만** 적용된다.
- 존재하지 않는 코드를 넣으면 **무시하고 계산을 진행**한다. 오류로 막지 않는다.
- 정률 쿠폰은 ②가 끝난 금액을 기준으로 계산한다.
- **쿠폰 할인액이 ② 적용 후 금액보다 크더라도 쿠폰 적용 후 금액은 0원에서 멈춘다. 음수가 되지 않는다.**

---

## 배송비

- 기본 3,000원
- **상품 합계(①)가 50,000원 이상이면 무료**
- 판단 기준은 **할인 전 금액**이다

---

## 계산 예시

12,000원짜리 3개를 골드 회원이 `WELCOME5000` 쿠폰으로 주문한 경우.

```
① 상품 합계          36,000
② 골드 5% 할인       -1,800   → 34,200
③ 쿠폰 5,000원      -5,000   → 29,200
④ 배송비             3,000   (합계 36,000원 < 50,000원)
─────────────────────────────
⑤ 최종              32,200
```

---

## 아직 정해지지 않은 것 (연습용으로 남겨둔 지점)

이 항목들은 **일부러 애매하게 두었다.** 실제 유지보수 요청이 대개 이런 데서 온다.

**1. 배송비 무료 기준을 할인 전으로 볼 것인가, 할인 후로 볼 것인가**
현재는 **할인 전(①)** 기준이다. 할인 후 기준으로 바꾸면, 할인을 많이 받은 주문이
오히려 배송비를 내게 된다. 어느 쪽이 맞는지는 정책 판단이 필요하다.

**2. 쿠폰 할인액이 상품 금액보다 크면 어떻게 되는가** *(확정)*
쿠폰 할인 후 금액이 0원 미만이 되면 **0원으로 고정한다.** 최종 금액은 배송비만 부과된다.
예: 10,000원 주문에 `BIGSALE`(50,000원 할인) 적용 → 쿠폰 적용 후 0원, 최종 3,000원(배송비).

**3. 주말 주문에 대한 정책이 없다**
요청에 `is_weekend`(주말 여부)를 받고는 있지만 계산에 쓰지 않는다.
주말 배송비 면제나 할증 같은 정책이 붙을 자리다.
